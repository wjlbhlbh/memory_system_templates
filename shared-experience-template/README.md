# AI 通用经验库

这是通用经验库模板。请将本目录内容复制到一个独立的同步目录；不要在模板仓库内积累个人经验。复制后的目录保存经验证、换一个项目仍适用的工具使用、排错和任务做法。项目专属事实留在该项目的 `.ai_memory/pitfalls.md`。经验库不需要单独创建 Git 仓库，也不保存完整对话或调用日志。

## 每台电脑设置一次

在本目录运行 `powershell -ExecutionPolicy Bypass -File .\setup-this-machine.ps1`。脚本把本机实际目录写入当前用户的 `AI_EXPERIENCE_DIR` 环境变量。重启 AI 编程工具后，工具才能读到新的变量；另一台电脑即使使用不同盘符，也运行同一个脚本即可。

## 使用方式

- 确定任务后，在相关操作前或首次失败准备重试时，用工具名、报错码、现象关键词搜索 `entries/EXP-*.md` 和当前项目的 `.ai_memory/pitfalls.md`。只打开命中的条目；不要在新会话启动时通读整个经验库。
- 找到经验后先核对适用范围和当前工具状态，不把旧记录当作永远正确的命令。
- 只有办法已实际验证、以后可能再用时才写入。先搜索是否已有同类记录；项目专属经验写项目文件，跨项目通用经验在 `entries/` 新建一个文件。
- 不写密钥、令牌、个人信息、客户数据、完整日志或业务项目源码。

## 新经验格式

每条经验单独保存为 `entries/EXP-日期时间-随机短码.md`，避免多台电脑同时改同一个总文件。内容保持简短：

```markdown
# 简短标题
- **状态**: active
- **触发线索**: 工具名、报错码、常见现象和同义说法
- **适用范围**: 哪些工具、系统或条件下有效
- **原因**: 已确认的原因；未知就写未知
- **有效做法**: 可执行的步骤
- **验证方式**: 如何确认问题真正解决
- **最后验证**: YYYY-MM-DD
- **证据**: 可公开的最小证据或简短来源；不含敏感内容
```

记录失效时改为 `stale`，有替代方案时改为 `superseded` 并指向新文件。同步可能有延迟；两台电脑不要同时编辑同一条经验。

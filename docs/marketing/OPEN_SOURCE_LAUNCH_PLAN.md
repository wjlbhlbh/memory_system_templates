# Open Source Launch Plan

Goal: make AI Memory System Templates easy to find, easy to understand, easy to try, and easy to share.

## Positioning

**Short description:** AI agent memory system and Memory Bank templates for reliable, tool-agnostic AI coding workflows.

**One-liner:** Give Codex, Claude Code, Cursor, Cline, OpenCode, Roo Code, and other AI coding agents a verified project memory layer that survives context loss and tool switching.

**Audience:**
- Individual developers using AI coding assistants daily.
- Open-source maintainers who want safer AI-agent contributions.
- Teams using multiple LLMs or agents on long-running projects.
- Developers working on monorepos, full-stack apps, and projects with frequent handoffs.

## Launch Post Drafts

### English

I open-sourced AI Memory System Templates: a tool-agnostic project memory layer for AI coding agents.

It gives Codex, Claude Code, Cursor, Cline, OpenCode, Roo Code, and AGENTS.md-compatible tools a shared `.ai_memory` structure with fast startup, active context, verified progress, task packs, module memory, searchable history, and health checks.

If your AI coding workflow loses context after long sessions or tool switching, this is built for that pain.

### 中文

我开源了一套 AI 编程项目记忆系统：AI Memory System Templates。

它不是单个 prompt，而是一套 `.ai_memory` 工程记忆层，支持 Codex、Claude Code、Cursor、Cline、OpenCode、Roo Code 和 AGENTS.md 生态工具。核心目标是解决 AI 编程里的上下文断片、重复分析、交接混乱、历史膨胀和“没验证就说完成”。

欢迎试用、star、提 issue，也欢迎贡献新的工具适配器和真实项目示例。

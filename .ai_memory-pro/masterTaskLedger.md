# 全局开发任务账本 (Master Task Ledger)

> 用途：这是多 LLM、多轮次、跨模块开发的共享地图。这里不写长需求正文，只写可认领、可验证、可交接的任务索引。

## 使用规则
- 新会话完成 Fast startup 后，只有在任务涉及长任务、多 Agent、跨模块协作、历史接力或用户明确要求继续项目计划时，才读取本文档。
- 认领任务时标记 `[IN_PROGRESS]`，写明日期、模型/工具、负责人、locked files 和当前任务包。
- 完成任务时标记 `[DONE]`，必须写 verification evidence、关键交接点和后续任务入口。
- 阻塞任务标记 `[BLOCKED]`，必须写阻塞原因、需要谁处理、恢复条件。
- 每个任务必须能在一次 LLM 会话内形成独立闭环；如果不能，先拆成更小的任务包。
- 每个任务包必须在本文档有 backlink；每个账本任务也必须指向对应 `task-packs/*.md` 或明确写 `无`。
- 本文档只保留任务索引和状态，不粘贴长设计、长日志或大段代码。

## 状态约定
- `[READY]`：可认领
- `[IN_PROGRESS]`：进行中，已有负责人
- `[BLOCKED]`：被外部条件或关键歧义阻塞
- `[DONE]`：已实现并有 verification evidence
- `[ARCHIVED]`：历史任务，详情已移入 `history/`

```markdown
- **模块**:

- **交接要点**:

```

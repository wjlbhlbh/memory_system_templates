# Code of Conduct

This project exists to make AI coding workflows more reliable, understandable, and welcoming across tools and communities.

## Expected behavior

- Be respectful and specific.
- Assume good intent, but accept correction quickly.
- Discuss ideas, tradeoffs, and evidence rather than attacking people.
- Keep examples safe: do not post secrets, private logs, production data, or personal information.
- Help newcomers understand the project before asking them to change their workflow.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without explicit permission.
- Repeatedly derailing issues or pull requests.
- Using the project to distribute malware, credential theft, or unsafe automation patterns.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or report abuse when behavior harms the community. If you need to report a conduct issue, use a private channel such as GitHub Security Advisory or contact the maintainer directly.

This is a short project-specific code of conduct inspired by common open-source community standards.

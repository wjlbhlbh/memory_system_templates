# Roadmap

This roadmap focuses on making AI Memory System Templates easier to discover, easier to adopt, and safer to use across AI coding tools.

## Now

- Keep the one-file state-aware startup, task-pack budgets, and context-health diagnostics regression-tested.
- Collect feedback on requirement baseline initialization, direct requirement replacement, compaction, and migration workflows.

- Keep the Pro template stable and lightweight.
- Improve README discoverability for AI agent memory, Memory Bank, context engineering, Codex, Claude Code, Cursor, Cline, and AGENTS.md searches.
- Collect real user feedback through structured issues and discussions.
- Add example workflows that show context recovery, task packs, and module memory in practice.

## Next

- Add `examples/minimal-script/` and `examples/fullstack-app/`.
- Add a short demo script or terminal recording guide.
- Add cross-platform `pwsh` verification notes for macOS and Linux.
- Improve `search-memory.ps1` output formats for AI agents and humans.
- Add more adapters based on community requests.

## Later

- Package the initializer for easier installation through npm, pipx, winget, or a signed release archive.
- Add a small CLI wrapper for `init-memory`, `sync-adapters`, `search-memory`, and `verify-memory`.
- Publish versioned releases with migration notes.
- Build a gallery of real-world `.ai_memory` patterns from different project types.

## Good first issues

- Add or improve documentation examples.
- Test initialization on a new project type and report missing setup fields.
- Add a tool adapter with official docs and a minimal template.
- Improve validation messages in `tests/verify-memory-system.ps1`.
- Translate key sections while preserving English search keywords.
